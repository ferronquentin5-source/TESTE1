Nestio Index

Un petit tableau de bord personnel pour retrouver ses dossiers, liens, projets et inspirations au même endroit.

## Ouvrir le site

Le site est statique et ne nécessite aucune installation : ouvrez simplement `index.html` dans votre navigateur.

## Rubriques

- **Dossiers** — les dossiers à garder à portée de main
- **Liens** — les sites et outils utiles
- **Projets** — les projets à suivre
- **Inspirations** — les idées et références à conserver

Les rubriques se parcourent depuis le menu latéral. Le projet ne contient pas de formulaire d’ajout : son contenu peut être adapté au fil des besoins.

## Fichiers principaux

- `index.html` — la page et ses styles
- `outputs/nestio-index.svg` — le monogramme du site

## Technologies

HTML, CSS et JavaScript, sans dépendances ni étape de compilation.
